# TabVault plan

Phases: 0 setup, 1 MVP (suspend + sessions), 2 workspaces + search + command palette,
3 polish/hardening + export/import + snapshots, 4 Web Store launch, 5 opt-in content indexing + sync, 6 Pro (encrypted sync).

Decisions made so far: MIT license, native `tabs.discard` for suspending, content indexing deferred to v1.1,
UI in plain TypeScript for the MVP (Svelte can be adopted when the UI grows).
