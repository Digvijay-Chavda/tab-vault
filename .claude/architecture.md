# Architecture

## Stack

WXT 0.21 (build tool and manifest generation), TypeScript (strict), Dexie 4 (IndexedDB), MiniSearch (search), Vitest (unit),
Playwright driving real Chromium (e2e), ESLint 10. No UI framework: the popup and options page are plain DOM built with
`textContent` and a few static SVG icons.

## Data model

IndexedDB database `tabvault` (Dexie). **Never edit an existing `.version(n)`; add a new one with `.upgrade` if data must change.**

| Version | Tables |
|---|---|
| 1 | `sessions` (`++id, createdAt, name`) |
| 2 | `sessions` (+`kind`), `workspaces` (`++id, name, updatedAt`) |
| 3 | `stash` (`++id, createdAt, url`), `notes` (primary key `key`, `updatedAt`) |

`SavedTab = { url, title, favIconUrl?, pinned?, group?: { title, color } }`. Session `kind`: `manual | auto | archive`.
Backups are JSON with `version: 1`; stash, notes and tab groups are optional fields, so old backups still import.
Imports only accept http(s) URLs and sanitize everything (see `backup.ts` and `tests/unit/backup.test.ts`, `notes.test.ts`).

### chrome.storage keys

| Area | Key | Content |
|---|---|---|
| sync + local | `settings` | Settings object (sync preferred, local fallback). |
| local | `stats` | `{ suspendedTotal }` |
| local | `schedules`, `schedulesFired` | Workspace schedules and the last local day each fired. |
| local | `lastBackupAt` | Epoch ms of the last backup file. |
| session | `lastActive` | tabId to epoch ms (idle detection). |
| session | `activeWorkspaces` | windowId to workspaceId. |
| session | `popupUi` | Last popup view and filter. |

### Settings (see `types.ts`, validated by `sanitizeSettings`)

idleMinutes, suspendPinned, suspendAudible, whitelist, autoSnapshots, autoGroup, minGroupSize, warnDuplicates,
dupeAction (`badge | switch`), archiveDays (0 = off, max 365), backupDays (0 = off, max 90), theme (`system | light | dark`),
density (`comfortable | compact`), groupRules. Adding a setting means: type + default, `sanitizeSettings`, options page
(HTML + load + save), a unit test in `settings-schema.test.ts`.

## Background flows

- **Alarms**: `tabvault-sweep` every minute (suspend idle tabs, run due workspace schedules); `tabvault-snapshot` every
  15 minutes (`housekeeping`: auto snapshot if enabled, `archiveStale`, scheduled backup if due).
- **Badge**: `updateBadge()` counts `findDuplicateIds` and sets the toolbar badge and tooltip; debounced 300 ms from tab events
  and from settings changes.
- **Switch to existing tab** (`dupeAction === 'switch'`): on `tabs.onUpdated` with a new URL, `duplicateOf()` finds another
  tab with the same address in the same window; the old tab is focused and the new one closed. Pinned tabs never trigger it.
- **Auto-group**: debounced per window after page loads when `autoGroup` is on; the resulting group change does not re-trigger it.
- **Commands** (`chrome.commands`, four allowed per extension): `_execute_action` Ctrl/Cmd+Shift+K, `stash-tab` Alt+Shift+S,
  `panic` Alt+Shift+P, `group-tabs` Alt+Shift+G.

## Popup flows

- `render()` rebuilds `#main` from scratch each time; a token discards stale renders; scroll position is kept; tab events
  trigger a 250 ms debounced re-render only for the Tabs and Insights views or when searching, and never while a dialog or
  menu is open.
- Query starting with `>` shows the command palette (`COMMANDS` array); otherwise non-empty text is search.
- `item()` builds every list row and pushes its click handler into `actions[]`, which the keyboard (Up, Down, Enter) uses.
- Multi-select state (`picked`, `lastPicked`, `visibleIds`) lives at module level and survives re-renders.
- `dismissPopup()` calls `window.close()` after jumping somewhere. In e2e the page is a normal tab, so the test stubs
  `globalThis.close`.
- `askForm()` is the inline dialog; `openMenu()` the context menu. Both close on Escape and outside click.

## Permissions (and why)

`tabs` (titles, URLs, discard), `tabGroups` (Chrome only; omitted from the Firefox manifest), `storage`, `alarms`,
`sessions` (recently closed), `downloads` (backup files). **No host permissions, no content scripts, no remote code.**
Adding a permission forces Chrome to ask existing users to re-approve; update `PRIVACY.md`, `docs/STORE_LISTING.md` and the
README permission table in the same change.

## Browser support

Chrome and Brave (MV3). Firefox: experimental MV3 build via `npm run build:firefox` (WXT defaults Firefox to MV2, which
lacks `chrome.action`, hence `--mv3`); tab-group code checks for `chrome.tabGroups` before use. Untested in Firefox.
